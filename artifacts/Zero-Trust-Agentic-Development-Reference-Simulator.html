Zero Trust for Agentic Development

An interactive reference and simulation environment for deploying autonomous AI agents securely — built from Anthropic's Zero Trust for AI Agents framework and the OWASP GenAI / Agentic Security Initiative. Use the tabs on the left to move between reference material and hands-on simulators.

Why this matters now

Frontier models compress the vulnerability-to-exploit timeline from months to hours, at near-zero marginal cost. Agents add a second dimension of exposure: they interpret goals, choose tools, and execute multi-step operations without a human validating every step. Traditional access controls do not stop an agent from misusing permissions it legitimately holds — which is why Zero Trust, re-shaped for agentic systems, is the baseline rather than an upgrade.

Five foundational principles

Never trust, always verify

Every access request undergoes authentication and authorization regardless of origin. Internal network traffic gets the same scrutiny as external.

Assume breach

Architect for compromise from day one. Segment by identity so that breaching one system doesn't grant access to others. The question is when the blast radius gets tested, not if.

Least agency

OWASP's extension of least privilege: constrain not just what an agent can access, but what each tool it holds can do, how often, and where.

Impossible vs. tedious test

Ask of every control: does it make the attack impossible, or just tedious? Friction-based controls fail against attackers with unlimited patience and near-zero per-attempt cost. Prefer removing a capability over throttling it.

Agentic system thinking

Treat the agent as a distributed system — model, tools, memory, and every sub-agent identity involved — not a single software component. Security has to cover the whole surface, not just the entry point.

Defensive Operations at Machine Speed

Securing the agents is half the work. Running security operations fast enough to contend with AI-accelerated attackers is the other half.

The shift: bookkeeping to humans off, decisions to humans on

Agentic adversaries can probe hundreds or thousands of systems in the time a human analyst reviews one alert. The fix is not removing humans from the loop — it's moving them off evidence collection and onto containment, disclosure, and customer-communication decisions.

Trust through verification — even for your own defensive agents

Agentic SOAR capabilities carry their own blast radius. Run defensive agents in hardened environments, scope their automated responses to specific bounded actions, require human approval for high-impact responses, and log/trace/review their actions with the same rigor as any other agent. Don't extend blind trust to your own automation.

Explainability self-check

For regulated data (financial, health, personal) this is not optional. Ask your team honestly:

  • Would we know within an hour if an agent went rogue?
  • Can the on-call engineer take a weekend off without worrying about undetected agent misbehavior?
  • Can we trace any specific agent action back to its triggering input and reasoning steps?

If any answer is "not sure" — Phase 8 (and likely Phases 3–7) need more work before scaling the deployment.
